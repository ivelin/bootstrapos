# Targeted distribution channels

Bootstrap OS is harness-agnostic. These are the named agent environments we target for Path 1 install and hosted MCP.

| Channel | Product page | Role |
|---------|--------------|------|
| Grok Bot | https://x.ai/bot | Persistent agent + cloud computer |
| Claude Cowork | https://claude.com/product/cowork | Persistent agent + computer |
| ChatGPT Work | https://chatgpt.com/work | Team ChatGPT workspace |
| ChatGPT Dot | https://chatgpt.com/features/dots/ | Always-on agent + own cloud computer |
| OpenClaw | https://openclaw.ai | Open agent harness |
| Hermes | https://hermes-agent.nousresearch.com | Open agent harness |

Any assistant that can read a URL or call MCP with a Bearer is still first-class. Named rows are distribution targets, not a required stack.

Path 1 front door: https://pirin.ai/bootstrap-os and this repo. Invite + accept: [`mcp/docs/INVITE.md`](../mcp/docs/INVITE.md).
