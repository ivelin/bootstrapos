# Clock examples

**Teaching, not a live board.** These scenes teach the locked 5 × 3 clocks. Do not copy them onto a real company. Do not treat this page as evidence. Do not Advance from an example.

**One fictional company only:** household jobs — parents who already pay a cleaner vs founder butler vs our house.

Every week answers two questions: **where is the bet**, and **what kind of week**.

- Journey (place): Write the bet / Filter cheaply / Ground it / Build tiny slice / Try with real people
- Loop (week): Ask / Do / Write back

Labels first. Speak the names. Do not number cells at a founder.

Do takes the station’s shape. It is not a synonym for Build. Write back does not promote. Build / Write back may kill. A kill stays at that station. Do **not** reset to Write the bet / Ask.

Locked table and path live on the constitution: [Fifteen cells](operating-system.md#fifteen-cells-journey-rung--loop-week) · [End-to-end path](operating-system.md#end-to-end-path).

## Write the bet

### Ask

**Do.** Name three groups: parents who already pay a cleaner, a founder who wants a butler, and our own house. Write what “works” means for each. Write the kill line before anyone ranks: kill if there is no paid analog.

**Do not.** Build a landing page. Interview parents. Rank a favorite. Open a bot. Call this a live board.

**Write back saves.** The three groups, what “works” means, and the kill line — labeled **stated**. Not a rank.

### Do

**Do.** Write one page: household jobs for people who already pay a cleaner, versus a founder butler, versus our house. Label it a hypothesis.

**Do not.** Ship a landing page. Book interviews. Build a bot. Treat “our house” as proof.

**Write back saves.** The one-page thesis as stated. Next is Filter, or stay if the page is mush.

### Write back

**Do.** Save the thesis and three groups as stated. Check the kill line is written.

**Do not.** Advance because the page looks complete. Promote parents. Hide the second idea inside the first.

**Write back saves.** Stated thesis + groups + kill line. Next is Filter if the page is real; stay if mush.

## Filter cheaply

### Ask

**Do.** Keep the same forced choice. Name a cheap signal that would demote a group. Sims stay synthetic.

**Do not.** Call a friend. Treat a chat model as Ground. Advance.

**Write back saves.** The question and the cheap-signal rule. Still hold.

### Do

**Do.** Read cleaner ads, calendar apps, and “a chat model already does this.” Run the same forced choice on paper. Parents first on paper if the cheap signal says so.

**Do not.** Call a parent. Label a sim as heard. Promote. Start a product.

**Write back saves.** Paper rank as **synthetic**. Still hold.

### Write back

**Do.** Write the paper rank. Label it synthetic. Keep promote on hold.

**Do not.** Advance to Ground because the spreadsheet looks tidy. Call this observed.

**Write back saves.** Synthetic rank + why parents sit first on paper. Do not Advance.

## Ground it

### Ask

**Do.** Who talks this week: five parents who already pay a cleaner. What behavior counts: they send last month’s job list. A smile is not interest.

**Do not.** Build the product. Count a Filter sim as heard. Use “cool idea” as the signal.

**Write back saves.** The talk list and the behavior rule.

### Do

**Do.** Talk to those parents, or run a waitlist with friction. Ask for last month’s job list.

**Do not.** Ship a slice. Relabel a Filter sim as heard. Count compliments.

**Write back saves.** Who sent a list versus who smiled.

### Write back

**Do.** Separate observed (lists sent) from still synthetic. The founder gates Ground-done.

**Do not.** Advance because five calls happened. Treat a smile as interest.

**Write back saves.** Observed versus still synthetic. Founder yes required to leave Ground.

## Build tiny slice

### Ask

**Do.** What can fail in the lab. Ready-for-human-eyes line. Smallest slice: one job text drafts a vendor SMS and does not send.

**Do not.** Put it in a household. Call tests Try. Advance.

**Write back saves.** The fail list and the eyes line.

### Do

**Do.** Design and build that smallest slice. Run tests.

**Do not.** Text a real vendor. Hand it to a parent. Skip tests.

**Write back saves.** What ran.

### Write back

**Do.** Save bugs and what ran. Tests green and zero households used it is a kill candidate. Engineering green is not demand.

**Do not.** Advance to Try. Reset to Write the bet / Ask. Pretend green tests are use.

**Write back saves.** Lab result. A kill stays here. Do not reset to Write the bet / Ask.

## Try with real people

Only if the founder did **not** kill at Build. A Build kill stays at Build / Write back.

### Ask

**Do.** What use would count: a parent sends a real Saturday job and accepts the draft. Who, this week, in their life — not ours.

**Do not.** Open a Grow pack. Count “looks good” in Slack as use.

**Write back saves.** The use rule and who.

### Do

**Do.** Put the slice in their hands. Watch what they did.

**Do not.** Demo in our house and call it their Saturday. Count Slack praise.

**Write back saves.** What they did.

### Write back

**Do.** Record observed use or no use. Only here can that support a Grow pack.

**Do not.** Open Grow on compliments. Reset to Write the bet / Ask after a kill.

**Write back saves.** Use or no use. Grow pack stays closed unless observed use exists.
