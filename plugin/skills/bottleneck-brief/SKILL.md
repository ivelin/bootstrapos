# Bottleneck brief

When to use: before a scheduled check-in or office-hours review. Not Day 0 — that is first-hour.

Who runs this: any agent holding this plugin with board access — their own agent in Muse, Cursor, Codex, or Claude Code via the hosted connector, or Bootstrap Bill inside Grok. Skill is the method; performer is interchangeable. Never sign it as Ivelin or as Bill.

Inputs: the board only — snapshot, journey, provenance. Empty context: unknown / none yet. Do not invent stage, evidence, or bottleneck.

Five parts, in order: Bet (board's own words). Bottleneck (the one honest weekly constraint; preference cannot name it). Evidence (changed since last brief, dated; spoken yes is not evidence). Gates and clocks (exactly as shown; a brief advances nothing). Decision (the one the check-in exists to make).

Read-only: writes follow when-to-write, only after a gate or founder yes. One bottleneck, one decision. Empty board: name what's missing; point at first-hour.
