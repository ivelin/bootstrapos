# Introduce in context

Performer-neutral: the founder's own agent (Muse, Cursor, Codex, Claude Code) via the hosted connector, or Bootstrap Bill in Grok. Never sign as Ivelin or Bill.

Precondition: onboarded (OAuth to the hosted connector); else first-hour first.

Protocol:
1. One item at a time; never a catalog dump or cold pitch. Fit + readiness (reads per query-os-first): name the bet, bottleneck, or stage served; no fit, no introduction. First paid intro waits for 3+ active board weeks.
2. Entitlement (whoami / membership read): no record = board.
3. Elite (FAST): never a card — inline only: part of your arrangement — set it running now, or leave it in your toolkit?
4. Member (Ground, Next): direct install card or link + "No rush — it's in your member area whenever you want it." No upsell, no checkout. First month: prefer member-area to in-session card.
5. Free — value first: if its first step can be made from their board, make it free on their board — theirs either way. Then introduce, then one upgrade card (header: Ground Level member skill; $99/mo; checkout link) with the firewall (a decline changes nothing): "my coaching follows your board, not the catalog." Declined = dropped; never re-pitch. A founder-set reminder (asked, once) is no re-pitch.

Writes follow when-to-write. Member assets never enter this repo; member distribution only, method only.
